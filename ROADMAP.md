# Roadmap

## Vision
A personal home-purchase planning tool: configure named scenarios with adjustable financial variables, overlay them on a 10-year net worth projection, and compare side-by-side. Generic enough for anyone, ships with sane defaults.

## Shipped
- Phase 1: Scaffold + financial engine

## Upcoming
- Phase 2: Core UI
- Phase 3: Projection chart
- Phase 4: Scenario management
- Phase 5: Mobile responsive
- Phase 6: GitHub Pages deploy

## Future
- **Excel export**: one-click `.xlsx` with scenario comparison table and pivot chart (`exceljs`)
- **Sensitivity analysis**: auto-generate a grid of scenarios varying one variable at a time
- **Rental income modeling**: model TN house / condo generating rent while held
- **Amortization table**: drill into a scenario's full amortization schedule
- **Tax deduction estimate**: rough mortgage interest deduction impact on take-home
